## 12. Project Delivery Process — 7 Gates

**Master Process (from site.json + Phases):** Discover → Design → Visualize → Plan (Budget + BOQ) → Build → Install → Deliver — Stop at gate you choose.

1. **Discover:** Brief — what space is today, must become, usage, city, budget band, plan/photos — consultation, site survey, measurement
2. **Design:** Space planning, concept, materials, moodboard, drawings — plan first, then still
3. **Visualize:** 3D stills first — one per key room, in-house not render farm, walkthrough/360 only if path matters, BOQ later
4. **Plan:** Budget with clarity, BOQ turns still into buildable scope, cost planning, vendor management, no fake sqft rate
5. **Build:** Civil, MEP, execution, site supervision, ISO 9001, mill connected to still, kitchens/wardrobes/counters drawn then made
6. **Install:** Furniture, joinery, lighting, signage, branding, MEP final
7. **Deliver:** Handover, snag list, warranty, aftercare

**Turnkey:** Goes all gates under one contract, one PM accountable.

**Design-Only:** Stops at gate 3 or 4 — 3D-only is complete engagement.

**Fit-Out:** Starts at gate 4 if design exists — review first, then scope, commercial, BOQ, site — do not execute external design not read against site.

**Renovation:** Starts with audit of existing, phased plan, after-hours work to avoid shutdown.
